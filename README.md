# First Person Boxing Field Manual

Next.js 15 App Router, TypeScript, Tailwind, Zod; pure static Cloudflare Pages export.

## Local checks

`npm install`, `npm run build`, `npm run typecheck`, `npm run check:codes`. Preview with `npx serve out`. Cloudflare build: `npm run build`; output: `out`; Node 22. No backend or secrets required.

## Production requirements

- Configure a real monitored contact channel and operator details before public launch. No invented email is shipped.
- Verify Discord and social URLs through the developer. Collect actual control screenshots, style evidence, code results and combo clips.
- Set Cloudflare Pages custom domain firstpersonboxing.org, check HTTPS and redirects. No deployment or DNS changes have been performed here.
- Validate deployed pages in Google Rich Results Test, then submit sitemap.xml to Search Console. FAQ markup does not guarantee a rich result.
- Run mobile QA and production PageSpeed Insights; LCP under 2s is a target, not a measured claim.
- Ads and analytics are disabled. The site is not yet ready for AdSense review. No ranking, indexing or approval guarantee.

The fan-site Organization does not use the game's official URL as sameAs: those are different identities. VideoGame links to the official experience. Statistics render as raw values until verified units and scales support proportional bars.
